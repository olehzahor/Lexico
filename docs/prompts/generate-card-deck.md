# Prompt for ChatGPT Work: generate a card deck

Attach the English word list (`.txt`, one word per line) and `Lexico/Resources/Cards/example_cards_en.json`, then paste this prompt:

```text
Создай новую колоду английских карточек из приложенного TXT-файла. Используй приложенный example_cards_en.json как точный образец структуры JSON. Не изменяй образец. Верни один полный скачиваемый JSON-файл, готовый для приложения.

Источник и карточки:
1. Обработай каждую непустую строку входного файла в исходном порядке. Одинаковые повторяющиеся строки обработай один раз, сохранив первое появление.
2. Если у слова есть несколько распространённых частей речи, создай отдельную карточку для каждой (например, существительное и глагол). Размести их подряд. У каждой карточки должны быть собственные переводы, уровень, категория и предложения. Не добавляй редкие или сомнительные части речи ради количества.
3. Поле word сохраняет исходное английское слово в словарной форме. part_of_speech использует сокращения из образца: n, v, adj, adv, pron, det, prep, conj, exclam. level — подходящий уровень CEFR от A1 до C2.
4. translations — массив кратких, точных русских переводов для указанной части речи; каждый элемент имеет поля text и language: "ru". Не смешивай переводы разных частей речи.

Категории принадлежат только этой колоде:
5. Проанализируй весь список и создай подходящую для него систему категорий. Группируй слова по понятной теме или функции, с учётом части речи. Не копируй автоматически категории образца и не ограничивайся ими. Избегай одной общей категории для всей колоды и множества категорий с единственной карточкой, если есть естественные группы.
6. В корне JSON добавь объект categories. Каждый использованный ключ категории должен иметь вид card.category.<английский_slug_в_snake_case>. Значение — объект с краткими естественными названиями на двух языках: {"en": "English name", "ru": "Русское название"}. Не используй ключ без определения в categories и не добавляй неиспользуемые категории.
7. В поле category каждой карточки укажи ключ из корневого categories. Категория должна действительно подходить именно этой карточке и её части речи. Названия категорий хранятся только в этом JSON; отдельный файл локализации не нужен.

Предложения и нумерация:
8. Для каждой карточки создай ровно 10 разных, естественных английских предложений с изучаемым словом именно в этой части речи. Допустимы естественные грамматические формы. Для каждого предложения дай точный русский перевод всего предложения.
9. Каждый элемент sentences имеет id и массив sentences ровно из двух объектов: сначала {"text": "...", "language": "en"}, затем {"text": "...", "language": "ru"}.
10. ID карточек — 1, 2, 3… без пропусков в порядке входных слов и карточек с разными частями речи. ID предложения = ID карточки × 100 + номер предложения от 1 до 10. ID действуют только внутри этой колоды; совпадения с другими колодами допустимы.

Структура и проверка:
11. Корневой JSON содержит ровно metadata, categories и words. В metadata укажи source_files с именем входного TXT-файла, source_counts с числом непустых строк файла до раскрытия частей речи, levels_included со списком реально использованных уровней, total_words с числом объектов в words, updated_at_utc с текущим временем UTC в ISO 8601 и schema_version: "2". Каждая карточка содержит поля id, word, part_of_speech, level, category, translations, sentences, language: "en".
12. Перед выдачей программно проверь, что JSON разбирается; все исходные слова представлены; ID карточек и предложений уникальны и соответствуют формуле; у каждой карточки ровно 10 предложений и корректные языки; все category ссылаются на существующие категории с непустыми en и ru; переводы и предложения соответствуют части речи.
13. Если список большой, обрабатывай его частями внутри задачи, затем собери один полный файл без сокращений. Отдельно от JSON кратко сообщи число входных строк, число карточек, число категорий, число предложений, число пропущенных повторов и результаты проверок.
```
